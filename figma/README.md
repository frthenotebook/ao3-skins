# About this folder

This folder contains CSS produced from Figma using Locofy. Classes aren't one-to-one with AO3 styling (and there are some things I will have to fix) but it helps in speeding up the process when putting together the final sheet.

These files are also used to generate preview thumbnails (combined with HTML files within this directory).

Included as well are previews on how the screen should look like.

## Disclaimer

**Provided images may not look like the final product**. For actual product images, go to `../skins/<SET_NAME>/img` (for instance, the NRC set can be found [here](../skins/NRC/img))
